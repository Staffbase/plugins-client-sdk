# Usage guides

The Plugin Client SDK provides asynchronous access to information from the
Staffbase app and methods that invoke native app behavior.

- [Getting started](getting-started.md): install and import the SDK, and make
  asynchronous requests.
- [App information](app-information.md): retrieve device and language details.
- [Native methods](native-methods.md): open links and use native sharing and
  file selection.
